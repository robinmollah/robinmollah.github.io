Comparing Local AI Image Models for Storytelling

I am exploring a system for producing short, story-driven videos for children. The target style is playful, semi-realistic 3D animation built from familiar stories.

I tested four local image-generation model families with the same story direction: two friends and a bear. Each row below represents one scene, and each column shows all available outputs from the selected model. Use the selectors to compare any two models side by side. The original variant numbers are preserved so each result can be traced back to its source image.
